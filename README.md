# México de Oro - Sitio Web & Políticas para TikTok Developer Portal

Este repositorio contiene el sitio web oficial y las páginas legales requeridas para el registro de la aplicación en el **TikTok Developer Portal**.

## 🚀 Pasos para Publicar en GitHub Pages en 2 Minutos

1. **Crear Repositorio:**
   - Ve a GitHub y crea un nuevo repositorio público con el nombre `mexico-de-oro` (o el que prefieras).

2. **Subir los Archivos:**
   - Sube los 3 archivos a la raíz de tu repositorio:
     - `index.html`
     - `terms.html`
     - `privacy.html`

3. **Activar GitHub Pages:**
   - Ve a **Settings** (Configuración) de tu repositorio en GitHub.
   - En el menú izquierdo, entra a **Pages**.
   - En **Source**, selecciona `Deploy from a branch`.
   - Selecciona la rama `main` (o `master`) y la carpeta `/ (root)`. Haz clic en **Save**.

4. **Copiar los Enlaces para TikTok:**
   Tus URLs públicas quedarán disponibles en 1 o 2 minutos con la siguiente estructura:
   - **Terms of Service URL:** `https://<tu-usuario>.github.io/mexico-de-oro/terms.html`
   - **Privacy Policy URL:** `https://<tu-usuario>.github.io/mexico-de-oro/privacy.html`

Pega exactamente esos enlaces en los campos obligatorios del formulario de TikTok Developer.
